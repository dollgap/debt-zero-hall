    후원금 대비 플랫폼 매출0%

    후원금 대비 비율은 “후원금에서 떼는 몫”이 아니라, 기업 마케팅 예산·구독료로 별도 발생하는 매출의 크기를 보여주는 지표입니다.

    자금은 이렇게 흐릅니다

    1. 1기업·개인 스폰서캠페인 예산 약정
    2. 2제휴 병원·공익재단에스크로 수납 · 채무 확인 · 세액공제 처리
    3. 3채무자 · 환자빚 직접 상환 → DEBT ZERO
    4. 4플랫폼트래픽·ESG 스폰서십·명예관 SaaS로 수익

    플랫폼은 돈을 만지지 않습니다. 후원금은 제휴 기관이 직접 수납·집행하고, 플랫폼은 기획비·구독료·광고 수익만 청구합니다.

    왜 안전하고, 투자가 붙는가

    ❌

    위험한 모델

    • 개인 돈을 모아 플랫폼이 직접 송금 → 전자금융거래법·기부금품법 위반 소지
    • 기부금에서 수수료 차감 → 여론 역풍, 신뢰 붕괴
    • 채무자에게 현금 지급 → 증여세·자금세탁 오해
    • 이름·사연 노출 → 개인정보·인권 문제
    ⭕

    현실적인 모델

    • 실제 수납·세액공제는 제휴 병원·공익재단이 직접 처리
    • 플랫폼은 트래픽 + 기업 ESG 스폰서십 + 명예관 PR/SaaS로 수익
    • 후원금 100% 집행 → 언론·기업 ESG 보고서에 쓰이는 서사
    • 사연은 기관 확인 + 익명 처리로 게시

    누군가에게 설명할 때는 이렇게

    1. 한 줄 정의“부자와 기업이 채무자의 빚을 대신 갚고, 그 이름이 병원 로비 명패에 남는 구조입니다.”
    2. 돈의 흐름“후원금은 제휴 병원·재단이 직접 받아 채무자에게 집행합니다. 플랫폼은 한 푼도 떼지 않습니다.”
    3. 수익 구조“수익은 기업의 ESG 캠페인 기획비, 병원·기업 명예관 구독료, 트래픽 제휴에서 나옵니다.”

    이 화면은 사업 구조를 설명하기 위한 컨셉 시뮬레이션입니다. 실제 서비스가 되려면 기부금품 모집·전자금융·개인정보·세무 검토가 선행되어야 하며, 본 프로토타입은 법률·투자 자문이 아닙니다.
